# 🚀 Projeto Tutorial de Git & Biografia de Linus Torvalds

Este projeto é um site acadêmico desenvolvido para fins de fixação de conceitos de desenvolvimento web fundamental (HTML5 e CSS3) e controle de versão com Git. 

---

## 📌 Sobre o Projeto

O objetivo da aplicação é servir como um guia educativo para iniciantes em **Git**, contendo um passo a passo prático com os principais comandos e conceitos, além de incluir uma subpágina dedicada à biografia de **Linus Torvalds**, o criador do Linux e do Git.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semantic**: Para estruturação de conteúdo acessível e bem organizado (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* **CSS3**: Para estilização visual, layout responsivo e formatação de texto e tabelas.
* **Git & GitHub**: Para versionamento e hospedagem do código fonte.

---

## 📁 Estrutura das Páginas

1. **Página Principal (`index.html`) - Tutorial de Git:**
   * Introdução ao que é o Git e para que serve.
   * Instalação e configuração inicial (`git config`).
   * Principais comandos (`git init`, `git add`, `git commit`, `git status`, `git push`, etc.).
   * Conceito de branches e mesclagem (`git branch`, `git merge`).
   * Menu de navegação para a subpágina.

2. **Subpágina (`linus.html` ou `biografia.html`) - Biografia de Linus Torvalds:**
   * História e trajetória do criador do Git.
   * Criação do Kernel Linux e do Git.
   * Prêmios e legado na tecnologia.
   * Link para retornar à página inicial.
